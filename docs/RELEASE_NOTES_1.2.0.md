# DK Annual Manager 1.2.0

Excel 내보내기와 달력 탐색을 개선한 기능 릴리스입니다.

## Excel 내보내기

### 사용자

**내 정보 → 내 휴가 엑셀 출력**에서 본인의 휴가 내역을 다음 범위로 내려받을 수 있습니다.

- 연간
- 월간
- 전체 기간

### 관리자

**관리 → 휴가 집계 → 휴가 집계 엑셀 출력**에서 다음 두 축을 조합할 수 있습니다.

대상:
- 전체 사용자
- 특정 사용자

기간:
- 연간
- 월간
- 전체 기간

Excel 파일에는 신청번호, 직원 정보(관리자 파일), 휴가 종류, 반차 구분, 시작/종료일, 신청일수, 선택 기간 내 실제 일수, 상태, 사유, 신청시각, 승인 정보, 취소 정보가 포함됩니다.

기간 필터는 신청 시작일이 아니라 실제 휴가 날짜(`leave_request_days`)를 기준으로 합니다. 예를 들어 9월 30일~10월 1일 2일 신청을 9월 월간으로 출력하면 신청일수 2.0일, 기간내일수 1.0일로 표시됩니다.

XLSX 생성은 외부 spreadsheet 패키지 없이 내부 OOXML writer로 처리하며, 사용자 입력은 수식이 아닌 문자열 셀로 기록합니다.

## 달력 이동 개선

- 내 정보의 월별 요약 카드를 누르면 해당 연·월 달력으로 바로 이동합니다.
- 달력 제목의 연도와 월을 각각 선택해 원하는 달로 즉시 이동할 수 있습니다.
- 기존 이전 달 / 이번 달 / 다음 달 버튼도 유지됩니다.
- 다른 연도의 달력을 볼 때 잔여 연차는 선택한 연도 기준으로 표시됩니다.

## 취소 상세 화면 수정

취소되거나 반려된 휴가 상세에서 취소 사유 입력칸과 취소 버튼이 노출될 수 있는 UI 문제를 보강했습니다.

이제 취소 액션은 본인 신청이면서:

- `pending`: 승인 전 신청 취소·삭제
- `approved`: 승인된 휴가 취소

일 때만 표시됩니다. `cancelled`와 `rejected`에서는 취소 액션을 강제로 숨기고 기존 처리 정보만 보여줍니다.

## 데이터베이스

이번 버전에는 신규 DB migration이 없습니다.

업데이트 후 `php bin/migrate.php` 실행 시 추가 적용 항목이 없어도 정상입니다.

## 업데이트

```bash
git pull origin main
composer install --no-dev --optimize-autoloader
composer audit --locked
php bin/migrate.php
php bin/check.php --production
```
