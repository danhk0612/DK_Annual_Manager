# DK Annual Manager 1.4.0

관리자 데이터 정리, 휴가 신청 안전장치, 목록 페이징과 달력 표시를 함께 개선한 기능 릴리스입니다.

## 취소·반려 휴가 기록 정리

**관리자 → 환경 설정 → 종료된 휴가 기록 정리**에서 더 이상 운영 중이지 않은 휴가 기록을 영구 정리할 수 있습니다.

삭제 대상:

- `cancelled`
- `rejected`
- 해당 신청의 `leave_request_days`
- 해당 신청을 참조하는 `annual_leave_ledger`
- 해당 신청 ID를 가리키는 개별 Audit Log

보존 대상:

- `pending`
- `approved`

작업은 DB 트랜잭션으로 수행하며 완료 후 삭제 건수만 담은 `leave.closed_history_purged` 요약 Audit Log를 남깁니다.

## 휴가 신청 UX

- 입사일이 등록되지 않은 사용자는 휴가를 신청할 수 없습니다.
- 관리자 직접 등록도 대상 직원의 입사일이 없으면 차단합니다.
- 시작일을 바꾸면 종료일도 우선 같은 날짜로 맞춥니다.
- 이후 종료일을 다시 선택하면 기존처럼 다일 휴가를 신청할 수 있습니다.
- 신청 기간에 과거 날짜가 포함되면 **이전 미기록 휴가를 작성하는 것이 맞는지** 한 번 확인합니다.
- 관리자 직접 등록·즉시 승인 경로에서는 Telegram 알림을 전송하지 않습니다.

## 승인/취소 화면

목록 안에 있던 관리자 메모와 취소 사유 입력칸을 제거했습니다.

- 승인 대기: 승인/반려 버튼 → dialog → 관리자 메모
- 전체 승인 목록: 승인 취소 버튼 → dialog → 취소 사유
- 사용자 신청 내역: 승인 휴가 취소 버튼 → dialog → 취소 사유

관리자 승인 화면의 기존 최근 30건 제한도 제거하고 전체 승인 목록을 표시합니다.

## 목록 페이징

주요 전체 목록에 공통 클라이언트 페이징을 적용했습니다.

페이지당 표시 수:

- 10건
- 20건
- 50건
- 100건

적용 범위에는 휴가 승인 대기, 전체 승인 목록, 신청 내역, 직원 목록, 연차 원장, 공휴일, 휴가 집계 직원 목록, 변경 이력, 달력 월 신청 목록이 포함됩니다.

Telegram의 `focus_request` 링크가 2페이지 이후 항목을 가리켜도 해당 페이지를 자동으로 선택합니다.

## 달력 개선

- 휴가 카드가 셀 왼쪽 가장자리에 너무 붙지 않도록 바깥/안쪽 여백을 늘렸습니다.
- 달력 연도는 **2000년 ~ 현재 연도 + 3년**으로 제한합니다.
- 범위 끝에서는 이전/다음 달 버튼을 비활성화합니다.
- 토요일이 비근무일이면 파란 계열 배경을 적용합니다.
- 일요일이 비근무일이면 빨간 계열 배경을 적용합니다.
- 토/일이 근무요일이면 주말 전용 배경을 적용하지 않습니다.
- 평일 비근무일은 기존 비근무일 색상을 유지합니다.
