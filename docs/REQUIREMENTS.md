# 요구사항

## 사용자

- Telegram으로 로그인한다.
- 본인의 입사일, 발생 연차, 사용 연차, 승인 대기, 잔여 연차를 열람한다.
- 월간/연간 휴가 일정을 열람한다.
- 날짜 또는 기간을 선택해 휴가를 신청한다.
- 휴가 유형을 선택한다.
- 신청 사유를 입력할 수 있다.
- 본인의 신청 내역과 처리 상태를 확인한다.
- 승인 전 신청을 취소할 수 있다.

## 관리자

- 사용자 등록, 수정, 활성/비활성 처리를 한다.
- 사용자의 입사일을 입력/수정한다.
- Telegram 계정 연결 상태를 관리한다.
- 관리자/사용자 권한을 지정한다.
- 휴가 신청을 승인 또는 반려한다.
- 휴가를 관리자 권한으로 직접 등록/수정/취소한다.
- 연차 이월, 특별 부여, 수동 조정을 기록한다.
- 전체 직원 월간/연간 휴가 달력과 집계를 열람한다.
- 휴가 유형과 연차 차감 여부를 관리한다.
- 공휴일 데이터를 갱신하고 수동 휴일을 관리한다.
- 주요 관리 작업의 변경 이력을 확인한다.

## Telegram

- Telegram OIDC 로그인
- 로그인 사용자의 Telegram ID를 내부 사용자와 연결
- 휴가 신청 시 관리자에게 Bot 메시지 전송
- 승인/반려 시 신청자에게 결과 전송
- 관리자에게 보낼 대상 chat ID는 설정파일에서 관리
- Telegram 메시지 전송 실패가 휴가 신청 자체를 무효화하지 않도록 처리

## 연차 계산

- 입사일을 원본 데이터로 사용한다.
- 법정 기본 연차를 자동 계산한다.
- 1년 미만의 월 개근 연차는 별도 발생 기록으로 관리할 수 있게 한다.
- 1년 이상은 법정 기본 15일 및 근속 가산을 계산한다.
- 최대 법정 기본값은 25일이다.
- 이월/특별부여/수동보정은 법정 기본 발생과 별도 거래로 기록한다.
- 승인된 연차/반차만 실제 사용량에 반영한다.
- 반려/취소 건은 사용량에서 제외한다.
- 승인 취소 시 기존 차감 거래를 역분개한다.

## 휴일/날짜 처리

- 토요일/일요일을 기본 비근무일로 본다.
- 공휴일 DB에 등록된 날짜는 기본적으로 연차 차감 대상에서 제외한다.
- 기간 신청 시 실제 차감 날짜를 `leave_request_days`에 펼쳐 저장한다.
- 반차는 지정 날짜에 0.5일로 저장한다.
- 회사 휴무일을 수동 등록할 수 있다.

## 설정 및 보안

- DB 접속 정보는 `config/config.php`에서 관리한다.
- Telegram client secret/bot token과 공휴일 API 키도 설정파일에서 관리한다.
- 실제 설정파일은 Git에서 제외한다.
- DB 접근은 PDO prepared statement를 사용한다.
- 세션 쿠키는 배포 환경에서 Secure/HttpOnly/SameSite를 적용한다.
- 모든 관리자 변경은 audit log 대상이 된다.
