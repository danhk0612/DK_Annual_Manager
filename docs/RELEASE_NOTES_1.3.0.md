# DK Annual Manager 1.3.0

관리자 대시보드에서 오늘 실제 휴가 중인 직원을 바로 확인할 수 있도록 휴가 현황 영역을 개선한 기능 릴리스입니다.

## 현재 휴가 중

관리자 대시보드에 **현재 휴가 중** 영역을 추가했습니다.

표시 기준:

- 신청 상태가 `approved`
- 오늘 날짜가 실제 휴가 날짜인 `leave_request_days.leave_date`에 존재

각 항목에는 다음 정보를 표시합니다.

- 직원명
- 부서
- 휴가 종류
- 반차인 경우 오전/오후
- 전체 신청 기간
- 오늘 해당 휴가 일수

오늘 휴가 중인 직원은 개수 제한 없이 목록에 표시합니다.

## 다가오는 휴가 기준 개선

기존 다가오는 휴가는 오늘부터 14일 후 사이에 휴가 날짜가 하나라도 있으면 표시했습니다.

v1.3.0부터는:

- 실제 첫 휴가일이 **내일부터 14일 후까지**
- 상태가 `approved`

인 신청만 표시합니다.

따라서 오늘 이미 휴가 중이고 내일까지 이어지는 다일 휴가는 **현재 휴가 중**에만 표시되고 **다가오는 휴가**에 중복해서 나오지 않습니다.

## 대시보드 배치

상단 주요 영역을 다음 4개로 구성했습니다.

1. 승인 대기
2. 현재 휴가 중
3. 다가오는 휴가
4. 관리 메뉴

대화면에서는 4열, 중간 화면에서는 2열, 모바일에서는 1열로 자동 재배치됩니다.

## 데이터베이스

신규 DB migration은 없습니다.
