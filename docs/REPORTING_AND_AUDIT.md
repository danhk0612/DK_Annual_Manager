# 집계 및 변경 이력

## 연차 집계 기준

직원별 연차 현황은 `annual_leave_ledger`를 기준으로 계산한다.

- 발생: `grant`
- 이월: `carryover`
- 조정: `adjustment`
- 복원: `reversal`
- 사용: `usage`의 음수 금액을 양수 사용량으로 표시
- 잔여: 해당 연도의 모든 원장 금액 합계

따라서 관리자 화면의 수동 조정과 승인된 연차/반차 사용이 동일한 원장 기준으로 집계된다.

## 월별 휴가 집계

월별 휴가 사용량은 `leave_requests.status = approved`인 신청의 `leave_request_days`를 기준으로 집계한다.

- 실제 휴가 날짜 기준으로 월을 구분한다.
- 휴가 종류(V/H/P/S/A)별로 합산한다.
- 반차는 저장된 `amount=0.5`를 그대로 합산한다.
- 반려/취소/승인 대기 신청은 집계하지 않는다.

## 관리자 대시보드

현재 연도를 기준으로 다음 정보를 표시한다.

- 활성 직원 수
- 승인 대기 신청 수
- 법정 발생 연차 합계
- 사용 연차 합계
- 연차 원장 잔여 합계
- 현재 월 승인 휴가 일수
- 최근 변경 이력

## Audit Log

`audit_logs` 테이블에 데이터 변경이 성공한 시점의 주요 작업을 기록한다.

기록 대상:

- 직원 추가/수정
- 사용자 본인 입사일 수정
- 휴가 신청/취소
- 관리자 승인/반려
- 연차 발생 동기화
- 이월/수동 연차 조정
- 공휴일 API 동기화
- 수동/회사 휴일 추가·삭제

로그에는 작업자, 작업 코드, 대상 종류/ID, 필요한 비민감 세부 정보, 요청 IP, 시간이 저장된다.

비밀번호, API 키, Telegram Bot Token 같은 설정 비밀값은 기록하지 않는다.
