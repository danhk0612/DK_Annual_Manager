# DK Annual Manager 1.4.2

설정 페이지 마지막 카드 배치와 좁은 영역의 페이징 UI를 개선한 핫픽스입니다.

## 설정 페이지 카드 배치

기존에는 `재설치 · 완전 초기화` 카드가 `grid-column: 1 / -1`로 전체 행을 강제로 차지해, 바로 위 `종료된 휴가 기록 정리` 카드 오른쪽에 빈 공간이 남았습니다.

v1.4.2에서는:

- 종료된 휴가 기록 정리: 왼쪽 열
- 재설치 · 완전 초기화: 오른쪽 열

로 같은 행에 배치합니다.

설정 그리드가 1열로 전환되는 1100px 이하에서는 기존처럼 각 카드가 한 줄씩 자연스럽게 쌓입니다.

## 좁은 영역 페이징 단순화

공통 목록 페이징을 다음처럼 개선했습니다.

- 전체 항목이 10건 이하라면 페이징 UI 자체를 표시하지 않습니다.
- 목록이 10건을 넘는 경우에만 페이지당 표시 수와 이동 컨트롤을 제공합니다.
- 화면 전체 폭이 아니라 **페이징 컨트롤 자체의 실제 폭**을 감지합니다.
- 좁은 카드에서는 자동으로 축약형으로 전환합니다.
- 축약형에서는 `이전 / 다음` 텍스트를 숨기고 화살표 아이콘만 표시합니다.
- `N건 중 X–Y건`은 `X–Y / N` 형식으로 줄입니다.
- `페이지당` 문구를 숨기고 숫자 선택기와 `건`만 유지합니다.

따라서 대시보드처럼 화면은 넓지만 카드 자체가 좁은 경우에도 자동으로 간결한 페이징이 적용됩니다.

## 데이터베이스

신규 DB migration은 없습니다.

## 업데이트

```bash
git pull origin main
composer install --no-dev --optimize-autoloader
composer audit --locked
php bin/migrate.php
php bin/check.php --production
```
