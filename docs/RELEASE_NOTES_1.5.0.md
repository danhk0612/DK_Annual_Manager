# DK Annual Manager 1.5.0

기존의 단순 휴가 기록 Excel 출력 기능을 **회사에서 바로 검토·집계에 사용할 수 있는 다중 시트 업무용 보고서**로 확장했습니다.

## 한 파일에서 확인하는 휴가 보고서

기존처럼 사용자/기간을 선택해 한 개의 `.xlsx` 파일을 내려받지만, 파일 내부는 목적별 시트로 구성됩니다.

공통 시트:

- **요약**: 대상, 기간, 출력 시각, 총 신청, 승인 휴가일, 연차 차감/비차감 일수, 상태별 신청 수
- **연도별 통계**: 실제 휴가일 기준 연도별 신청/승인/사용량
- **월별 통계**: 실제 휴가일 기준 연월별 신청/승인/사용량
- **휴가종류 통계**: 연차/반차/공가/병가/대체휴가별 사용량
- **연차 현황**: 선택 연도의 발생·이월·조정·복원·사용·순사용·잔여·총가용·소진율
- **신청 기록**: 신청 단위 상세 데이터
- **일자별 기록**: 통계의 원본이 되는 실제 휴가 날짜 단위 데이터
- **연도별 상세**: 데이터가 있는 연도마다 자동 생성
- **연월별 상세**: 데이터가 있는 연월마다 자동 생성

## 관리자 보고서 추가 기능

관리자 Excel에는 다음 시트가 추가됩니다.

- **직원별 통계**
- **부서별 통계**
- **검토 필요**
  - 승인 대기 신청
  - 신청 생성일보다 과거인 실제 휴가일이 포함된 소급 입력
  - 같은 직원의 같은 날짜에 승인 휴가가 여러 건 존재하는 경우
- **직원별 상세**: 전체 사용자 출력 시 직원별로 자동 분리

검토 필요 시트는 자동 판정 보조 자료이며 최종 판단은 신청 기록과 함께 확인해야 합니다.

## 기간 계산 기준

연간/월간 보고서는 신청 시작일이 아니라 **실제 휴가 날짜(`leave_request_days.leave_date`)**를 기준으로 합니다.

예를 들어 9월 30일~10월 1일 2일 휴가를 9월 보고서로 출력하면:

- 원신청일수: 2.0
- 범위내일수: 1.0
- 범위내실제일자: 9월 30일

로 표시됩니다.

## Excel 사용성

- 제목·설명·표 헤더 스타일
- 적절한 열 너비
- 헤더 고정
- 상세 표 자동 필터
- 날짜/시각/휴가 일수 형식
- 승인/대기/반려/취소 상태별 스타일
- 긴 사유·메모 줄바꿈
- 중복 시트명 자동 안전 처리
- Excel 수식 인젝션 방지를 위한 사용자 입력 inline string 처리

## 구현 방식

추가 spreadsheet 라이브러리나 PHP Zip 확장을 요구하지 않습니다.

기존 프로젝트의 OOXML writer를 확장해:

- 다중 worksheet
- workbook relationships
- 셀 스타일
- 숫자/날짜 형식
- merge cells
- freeze panes
- auto filter

를 직접 생성합니다.

자동 테스트에서는 XLSX ZIP 구조와 **모든 XML/relationship 파일의 well-formed 여부**를 검증합니다.

## 데이터베이스

신규 DB migration은 없습니다.

## 업데이트

```bash
git pull origin main
composer install --no-dev --optimize-autoloader
composer audit --locked
php bin/migrate.php
php bin/check.php --production
```
