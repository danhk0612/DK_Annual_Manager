# DK Annual Manager

PHP + MariaDB 기반의 소규모 조직용 연차·휴가 관리 웹 애플리케이션입니다.

기존 Excel 휴가 일정표의 월별 휴가 기록과 직원별 집계를 웹으로 이전하고, 입사일 기반 연차 계산, 휴가 신청/승인, Telegram 로그인·알림, 한국 공휴일 업데이트를 하나의 흐름으로 관리하는 것을 목표로 합니다.

## 핵심 기능

- Telegram 계정 로그인 및 사용자 연결
- 관리자 / 일반 사용자 권한 분리
- 직원 입사일 관리
- 입사일 기반 법정 연차 자동 계산
- 연차·반차·개인·병가·대체휴가(기타) 관리
- 날짜/기간 단위 휴가 신청
- 관리자 승인·반려·직접 등록
- 승인 결과 및 신청 알림 Telegram 전송
- 월간/연간 휴가 달력
- 직원별 발생·사용·잔여 연차 집계
- 한국 공휴일 데이터 업데이트 및 수동 휴일 관리
- 연차 이월 및 관리자 수동 조정
- 주요 변경 이력(Audit Log)

## 기술 스택

- PHP 8.2+
- MariaDB 10.6+
- HTML / CSS / JavaScript
- Composer
- Telegram Login (OpenID Connect)
- Telegram Bot API
- 공공데이터포털 한국천문연구원 특일 정보 API

## 개발 원칙

1. DB 접속 정보, Telegram 자격 증명, 외부 API 키는 저장소에 커밋하지 않습니다.
2. 실제 설정은 `config/config.php`에서 관리하고 저장소에는 `config/config.example.php`만 포함합니다.
3. 휴가 기록은 Excel처럼 사람×날짜 셀 구조로 저장하지 않고 `사용자 + 날짜 + 휴가유형` 중심으로 정규화합니다.
4. 법정 연차 계산과 회사별 보정/이월/특별휴가는 분리합니다.
5. 계산 결과만 저장하지 않고 발생·조정·사용 근거를 추적할 수 있게 합니다.
